Comprendre cette expérience

Les déplacements sont rejoués à partir de tables Q sauvegardées. Ce ne sont pas les épisodes historiques utilisés pour apprendre. La courbe mesure la politique sans exploration ; les séquences « Avec exploration » montrent comment elle se comporte avec le ε de l’entraînement.

Les égalités entre meilleures actions sont départagées au hasard avec une graine fixe. Au départ, les valeurs sont toutes nulles : le comportement est donc aléatoire même avec ε = 0. La glace reste glissante à toutes les étapes.

Les progrès ne sont pas forcément réguliers. Une tentative ne suffit pas à juger la qualité de la politique. Les premières tentatives sont affichées sans sélection de réussites ; la courbe utilise davantage d’épisodes.

Comment cette partie est-elle jouée ?

Chaque déplacement est calculé au moment où tu avances. Les probabilités de déplacement proviennent de Gymnasium, mais les tirages sont réalisés dans le navigateur. Aucune trajectoire enregistrée n’est utilisée.

L’agent choisit une meilleure action de sa table finale, sans exploration ni apprentissage. Les égalités sont départagées au hasard. La table Q est figée et la carte ne change pas.

Nouvelle partie garde le départ choisi et effectue de nouveaux tirages. Deux parties peuvent malgré tout suivre le même chemin. Le hasard du navigateur n’utilise pas les graines Python : ce mode sert à jouer, pas à reproduire l’évaluation chiffrée.

Les taux de réussite mesurés dans le projet concernent le départ habituel, la case 0. Ils ne prédisent pas le taux de réussite depuis les autres cases.

Les flèches décrivent l’action demandée ; la glissade peut envoyer l’agent dans une autre direction. Carte fixe 4 × 4, politique sans apprentissage pendant le jeu.
